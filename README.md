# Coach

אפליקציית מאמן אישי ותזונה. שלב 1: מסך יומי שקורא מ Health Connect צעדים, אנרגיה פעילה, תזונה, משקל, שינה, דופק, אימונים ומרחק, ומציג לכל נתון את המקור שלו ומצב: תקין, חלקי או חסר.

## בנייה

הבנייה נעשית ב EAS (הענן של Expo) עם הפרופיל `preview`, שמפיק קובץ APK להתקנה ישירה.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `src/screens/TodayScreen.tsx` | המסך היומי: תזונה, פעילות, שינה, משקל, האימון הבא, איכות נתונים |
| `src/health/today.ts` | קריאה מ Health Connect, איחוד רשומות שינה חופפות, הערכת איכות לכל נתון |
| `src/health/permissions.ts` | בדיקת זמינות, אתחול ובקשת הרשאות |
| `src/config/goals.ts` | יעדים יומיים ולוח האימונים השבועי |
| `src/config/sources.ts` | מיפוי שמות חבילות לשמות אפליקציות |
| `src/ui/` | ערכת צבעים ורכיבי תצוגה |
