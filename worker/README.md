# שרת ניתוח ארוחות

Cloudflare Worker שמקבל תמונה או תיאור של ארוחה, שולח ל Claude, ומחזיר פריטים עם גרמים, קלוריות, חלבון, פחמימות ושומן.

## סודות (מוגדרים ב Cloudflare בלבד, לא בקוד)

| שם | ערך |
| --- | --- |
| `ANTHROPIC_API_KEY` | מפתח מ console.anthropic.com |
| `APP_TOKEN` | קוד סודי אקראי. אותו קוד מוזן באפליקציה, במסך ההגדרות |
| `MODEL` | לא חובה. ברירת מחדל: claude-sonnet-5-5 |

## נקודות קצה

| נתיב | שימוש |
| --- | --- |
| `GET /health` | בדיקת חיים, בלי אימות |
| `POST /analyze` | גוף: `{ "image": "<base64 jpeg>", "text": "<הערה>" }`, כותרת `x-app-token` |

## מצב

לא בשימוש כרגע. בשלב האישי הצילום והניתוח נעשים ב Zepp, והאפליקציה קוראת את הארוחות מ Health Connect. השרת נשמר כחלופה אם Zepp ישתנה, וכבסיס להרחבה למשתמשים נוספים.
